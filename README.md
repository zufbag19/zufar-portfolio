# Персональный сайт Зуфара Фаритовича Багаутдинова

Современная переработка прежнего сайта Wix в статический сайт для GitHub Pages.

## Что внутри

- `index.html` — основная страница;
- `styles.css` — фирменная светлая тема: белый / графит / жёлтый;
- `script.js` — мобильное меню, анимации, фильтры материалов;
- адаптивная верстка для компьютеров и смартфонов.

## Публикация на GitHub Pages

1. Создать новый публичный репозиторий, например `zufar-portfolio`.
2. Загрузить файлы в корень ветки `main`.
3. В Settings → Pages выбрать Deploy from a branch → `main` → `/ (root)`.
4. После публикации сайт будет доступен по адресу вида `https://<username>.github.io/zufar-portfolio/`.

Если репозиторий назвать `<username>.github.io`, сайт будет открываться прямо по адресу `https://<username>.github.io/`.
